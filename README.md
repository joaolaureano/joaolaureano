<h3>About me</h3>

Backend engineer at **Mercado Livre**, writing Go services that support millions of daily package deliveries across Brazil. Before that, three years at **Dell Technologies** building incident automation for its global support infrastructure.

I care about distributed systems, performance and clean architecture, and I like to measure things before I believe them. On the side I build small open-source tools in Go and Java.

Outside of work: music, cinema and surfing.

<h3>Highlights</h3>

- [**pprof_advisor**](https://github.com/joaolaureano/pprof_advisor): offline Go CLI that ranks pprof hotspots and gives a statistical verdict on whether a patch actually helped
- [**go-router**](https://github.com/joaolaureano/go-router): dependency-free HTTP router for Go on a patricia trie, with lock-free lookups
- [**java-p2p**](https://github.com/joaolaureano/java-p2p): UDP peer-to-peer file sharing over a DHT of super-nodes, written from scratch in Java 21
- [**memorization**](https://github.com/joaolaureano/memorization): flashcards app built with Spec-Driven Development, running on AWS
