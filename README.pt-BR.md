<h3>Sobre mim</h3>

Engenheiro backend no **Mercado Livre**, escrevendo serviços em Go que sustentam milhões de entregas diárias de pacotes pelo Brasil. Antes disso, três anos na **Dell Technologies** construindo automações de incidentes para a infraestrutura global de suporte.

Gosto de sistemas distribuídos, performance e arquitetura limpa, e de medir antes de acreditar. Nas horas vagas construo pequenas ferramentas open source em Go e Java.

Fora do trabalho: música, cinema e surfe.

<h3>Destaques</h3>

- [**pprof_advisor**](https://github.com/joaolaureano/pprof_advisor): CLI offline em Go que ranqueia hotspots do pprof e dá um veredito estatístico sobre se um patch realmente melhorou
- [**go-router**](https://github.com/joaolaureano/go-router): roteador HTTP sem dependências para Go, sobre uma patricia trie com buscas lock-free
- [**java-p2p**](https://github.com/joaolaureano/java-p2p): compartilhamento de arquivos P2P via UDP sobre uma DHT de super-nós, do zero em Java 21
- [**memorization**](https://github.com/joaolaureano/memorization): app de flashcards construído com Spec-Driven Development, rodando na AWS
